Privacy Policy — Gembel Klip Uploader

Last updated: 19 November 2026

Overview

Gembel Klip Uploader ("the Application") is a personal tool operated by a single individual (the "Operator") to upload the Operator's own videos to the Operator's own YouTube channel (Gembel Klip) using the YouTube Data API. The Application is not offered to the public and has no users other than the Operator.

API services used

This Application uses YouTube API Services. By using this Application, the Operator agrees to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Data accessed

The Application requests a single OAuth scope: https://www.googleapis.com/auth/youtube.upload ("Manage your YouTube videos"). This scope is used only to upload video files and set their metadata (title, description, category, privacy status) on the Operator's own channel.

Data stored

OAuth credentials (access token and refresh token) are stored locally on the Operator's own computer in a private file with restricted permissions. No data is stored on any server, transmitted to any third party, sold, or used for advertising, analytics, or profiling.

Data sharing

No user data is shared with any third party, except the data transfer to Google/YouTube that is inherent in performing an upload requested by the Operator.

Revoking access

Access can be revoked at any time via the Google Account security page: https://myaccount.google.com/permissions. Revoking access immediately stops the Application from uploading.
